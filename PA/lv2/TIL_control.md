# 1 제어 개요와 시스템 응답(개루프/폐루프)


###  개루프 vs 폐루프
**Control(제어)** : 시스템의 출력(모터속도, 관절 각도, 온도 등)을 우리가 원하는 값 - 목표값(reference)로 만드는일

**개루프** :  목표값 -> 제어기 -> 시스템(플랜트)로 신호가 한방향으로만 흐릅니다<br>

**폐루프** : 센서가 출력으 ㄹ측정해 입력쪽으로 되먹임(피드백)하고, 목표값의 차이인 오차(error) e = r(목표값)-y(출력)를 제어기로 보내 계속 보정

***예시***<br> 
- 토스터(개루프) : 3분굽기라고 시간만 정합니다. 빵이 실제로 얼마나 탔는지 보지않음
- 에어컨(폐루프) : 온도센서가 실내 온도를 계속 재고, 목표 온도와의 차이만큼 냉방을 조절합니다.
- 로봇팔의 스텝 모터 vs 서보 모터 : 스텝 모터를 개루프로 쓰면 "1.8°씩 100번 돌아라"라는 명령만 보냅니다. 부하가 커서 스텝을 놓치면(탈조) 로봇은 그 사실조차 모릅니다. 서보 모터는 엔코더로 실제 각도를 재서 되먹임하므로 놓친 만큼 더 돌립니다 

### 장단점 비교

| 구분 | 개루프 | 폐루프 |
| --- | --- | --- |
| 센서 | 불필요 → 저렴·단순 | 필요 → 비용·복잡도 증가 |
| 외란(disturbance) 대응 | 불가 — 오차가 그대로 남음 | 자동 보정 |
| 모델 오차 대응 | 불가 — 모델이 틀리면 결과도 틀림 | 자동 보정 |
| 안정성 문제 | 없음 (시스템 자체가 안정하면) | **잘못 설계하면 발진·불안정** (2강) |
| 대표 예 | 토스터, 세탁기 타이머, 개루프 스텝 모터 | 에어컨, 서보 모터, 드론 자세 제어 |

<aside>

**핵심**: 피드백의 힘은 **"모르는 것에 대한 강건함"** 입니다. 부하가 얼마인지, 배터리 전압이 얼마나 떨어졌는지, 바람이 부는지 몰라도 — 오차를 재서 줄이는 구조 자체가 그 변화를 흡수합니다. 대신 그 대가로 **안정성**이라는 새 문제를 떠안습니다(2강 주제).

</aside>

## 시스템을 수학으로 -전달함수

제어기를 설계하려면 먼저 제어대상(플랜트)이 입력에 어떻게 반응하는지 알아야하빈다.

예: 모터 속도 $\omega(t)$ 와 입력 전압 $v(t)$ 의 관계(간략화):

$$
J\frac{d\omega}{dt} + b\,\omega = K\,v(t)
$$

여기서 $J$는 회전 관성, $b$는 마찰 계수, $K$는 토크 상수입니다. 미분방정식은 정확하지만 다루기 번거롭습니다. 그래서 제어공학은 **라플라스 변환**으로 미분방정식을 대수식으로 바꿉니다. 미분 $\frac{d}{dt}$ 이 $s$ 곱하기로 바뀌는 것이 핵심입니다.

$$
(Js + b)\,\Omega(s) = K\,V(s) \quad\Rightarrow\quad G(s) = \frac{\Omega(s)}{V(s)} = \frac{K}{Js + b}
$$

이 $G(s)$ — **입력의 라플라스 변환 대비 출력의 라플라스 변환의 비** — 를 **전달함수(transfer function)** 라고 합니다.

- $s$ 는 "미분 연산자"라고 읽어도 무방합니다. $s$ 가 많이 곱해져 있을수록 변화율에 민감한 시스템입니다.
- 전달함수의 **분모를 0으로 만드는** $s$ **값(극점)** 이 시스템의 운명(빠르기·진동·안정성)을 결정합니다.


### 위치를 미분하면 속도, 속도를 미분하면 가속도
### 속도를 적분하면 위치, 가속도를 적분하면 속도


### 1차 시스템 = 시정수 
- 현상 : 속도계값은 목표 RPM으로 점프하지않고, 빠르데 오르다가 점점 완만해지며, 어떤값에 눕습니다.
- 직관 : 모터에는 관성이 있어 속도가 한순간에 바뀔 수 없고, 속도가 올라갈수록 마찰과 역기전력이 커져 더 가속할 여력이 줄어듭니다. 즉 **"목표까지 남은거리에 비례해서 접근한다"** 

- 수식 :이 관계를 옮긴 것이 가장 단순한 패턴, 1차 시스템입니다. 표준형은 다음과 같습니다.

$$
G(s) = \frac{K}{\tau s + 1}
$$

- $K$: **정상상태 이득(DC gain)** — 입력 1을 오래 유지했을 때 출력이 최종적으로 도달하는 값
- $\tau$: **시정수(time constant)** — 반응의 "빠르기"를 나타내는 시간 단위 값

### 실생활 예시

- **전기 주전자**: 스위치를 켜면 물 온도가 지수 곡선으로 올라갑니다. 주전자의 시정수가 3분이면, 3분에 최종 온도차의 63%, 약 15분(5τ)이면 사실상 도달입니다.
- **DC 모터의 속도**: 전압을 계단으로 걸면 속도는 1차 응답으로 올라갑니다. 7강 실습에서 여러분이 모터에 PWM 계단을 주고 엔코더로 속도를 찍으면 — 이 곡선이 나오고, 거기서 τ를 직접 측정합니다.

<aside>

1차 시스템은 **절대 목표를 지나치지 않습니다(오버슈트 없음).** 에너지를 저장하는 요소가 하나뿐이라 "출렁일" 방법이 없기 때문입니다.

</aside>
