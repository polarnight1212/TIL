# C++ 메모리

## 스택과 힙

### 스택 
- 함수 호출마다 자동 확보/해제 
- 매우 빠름(포인터 이동)
- 크기가 컴파일 때 고정
- 함수가 끄나면 소멸
- ex) double v =1.2; Motor m;

### 힙
- 실행 중 원하는 크기로 할당
- 함수가 끝나도 살아남음
- (2강)지터의 원인
- 할당/해제 느리고 시간 불규칙
- 해제를 잊으면 메모리 누수
- autp p = std::make_shared<Motor>();

- 스택은 함수의 지역 변수가 사는곳
- 함수에 들어갈때 자동으로 확보되고 나갈때 자동으로 사라지며, 포인터만 움직이면 되니 빠름
- 힙은 실행중에 원하는 크기로 할당하는 자유영역
- 해제를 잊으면 메모리 누수
- 할당 해제가 느리고 시간이 불규칙함
